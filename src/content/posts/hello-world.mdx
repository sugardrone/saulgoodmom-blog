欢迎来到 **SaulGoodMom**。

## 为什么写博客

信息流读得越多，沉淀得越少。写作是把零散的输入重新组织成自己的理解的过程，
也是对抗遗忘最朴素的手段。所以有了这个站点。

## 会写些什么

- **工程实践**：踩过的坑、总结的方案、可复用的工具
- **开源观察**：读源码、用轮子、偶尔造点小轮子
- **杂谈**：读书、效率、以及一些不成熟的想法

## 关于本站

这是一个纯静态站点，用 [Astro](https://astro.build) 构建：

```bash
npm run dev     # 本地预览
npm run build   # 构建静态文件
```

代码高亮、暗色模式、RSS 都已就绪。评论基于 GitHub Discussions。

> 保持好奇，持续输出。

希望这些文字对你也有点用。
